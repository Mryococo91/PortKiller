# Port Killer

Windows utility to see **which process is using which port** and terminate it.

Free, open source (MIT). No account, no cloud, no telemetry.

The UI follows your Windows display language (English and French).

## Getting started

Double-click **PortKiller.exe**.

Keep the `runtime` folder next to the executable. Without it, the app cannot start.
